# 온기센터 데일리 홈페이지

센터 운영에 필요한 오늘 일정, 송영, 직원 업무, 식단, 소통, 준비물, 날씨, 제철 저녁 추천, 낙상 예방 운동과 명언을 한 페이지에서 확인하는 스크롤형 홈페이지입니다.

## 바로 보기

`index.html` 파일을 더블클릭하면 브라우저에서 열립니다.

## 내용 수정

1. 오른쪽 위의 **내용 편집** 버튼을 누릅니다.
2. 점선으로 표시되는 글자를 직접 수정합니다.
3. 화면 아래의 **변경 저장** 버튼을 누릅니다.

저장된 내용은 현재 브라우저의 로컬 저장소에 보관됩니다. 다른 컴퓨터와 자동 공유되지는 않습니다.

## GitHub에 올리기

이 폴더의 `index.html`과 `README.md`를 저장소에 업로드하면 됩니다. GitHub Pages를 켜면 별도 설치 없이 공개 홈페이지로 사용할 수 있습니다.

## 실제 운영 전 확인

- 센터명, 직원명, 송영 당번, 프로그램 일정은 예시 데이터입니다.
- 식단은 참고 형식이며 실제 주간 식단표로 교체해야 합니다.
- 날씨는 서울 좌표를 기준으로 Open-Meteo에서 표시합니다. 다른 지역이면 `index.html`의 latitude와 longitude 값을 바꾸세요.
- 낙상 예방 운동은 개인 상태에 맞게 의료진 또는 담당자의 지시에 따라 진행하세요.
